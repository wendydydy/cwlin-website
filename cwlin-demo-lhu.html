課程設計：一條智慧倉儲主線貫穿全學期

「資料結構」課程以智慧倉儲管理系統為唯一案例：每一章對應倉儲的一個功能——陣列＝16×16 儲位模型、堆疊與佇列＝操作歷史、樹/BST＝零件搜尋、Heap＝優先排程、雜湊＝儲位查詢、圖＝揀貨路徑、AI＝智慧倉儲預測。學生先在 Google Colab 完成 Python 雛型（期中），期末再延伸為完整專題；本頁展示的硬體版是學生自發完成的作品。

硬體架構Arduino Mega 2560 ＋ ESP32-S3 雙 MCU 分工；74HC595 / 74HC138 驅動矩陣、行掃描刷新
除錯實錄部分 LED 不亮：以電表量測發現模組排阻故障，更換後正常；ESP32 ALL 指令記憶體崩潰，修改邏輯後解決
可靠性EEPROM 斷電保存倉儲狀態；通訊恢復後 ESP32 自動向 Mega 發出 SYNC 重新同步
介面序列埠指令（SSCOM 等串口軟體）＋ Wi-Fi Web 介面；指令 add / del / all / cls
延伸方向RFID／條碼、雲端資料庫、儲位推薦演算法、APP 監控、繼電器工業控制
